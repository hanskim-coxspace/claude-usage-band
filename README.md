# usage-band

Claude Code 프롬프트 입력창 위에 사용량을 한 줄로 보여주는 배너 플러그인입니다.

Claude Chat(claude.ai)용 Chrome 확장은 `chrome/` 폴더에 있습니다 — 맨 아래 “Claude Chat용 브라우저 확장” 참고.

```
세션 ━━━━━━──── 62% 18:40 │ 주간 ━━━━━━━━── 82% 월 12:00 │ Fable ━━━━━━━━━─ 86%   [자세히]
```

- **세션**: 5시간 한도 사용률과 초기화 시각
- **주간**: 주간 한도 사용률과 초기화 시각
- **모델별 한도**: 요금제가 모델별로 따로 두는 주간 한도(예: Fable)
- **[자세히]**: 컨텍스트 창 사용률과 토큰 수, 세션 비용, 한도별 남은 시간

막대는 75%부터 주황, 90%부터 빨강으로 바뀌고, 한도가 90%를 넘으면 한 번 알림을 띄웁니다. 창이 좁으면 초기화 시각, 막대 순으로 줄여 한 줄을 유지합니다.

## 설치

### Claude 데스크톱 앱

1. 프롬프트 입력창 옆의 **+** 를 누릅니다.
2. **Plugins** 를 고릅니다.
3. **Add marketplace** 에 `hanskim-coxspace/claude-usage-band` 를 입력합니다.
4. 목록에서 `usage-band` 를 **Add plugin** 으로 추가합니다.

### 터미널의 Claude Code

프롬프트에서:

```
/plugin install usage-band --marketplace hanskim-coxspace/claude-usage-band
```

셸에서:

```
claude plugin install usage-band --marketplace hanskim-coxspace/claude-usage-band
```

마켓플레이스를 추가할지 물으면 `y`, 범위는 사용자(user)를 고르면 이후 모든 세션에서 로드됩니다.

## 켜고 끄기

- 데스크톱 앱: **+** → **Plugins** 에서 `usage-band` 를 켜거나 끕니다.
- 터미널: `/plugin` 메뉴에서 켜거나 끕니다.
- 잠깐만 가리려면 배너 오른쪽의 `[-]` (또는 `ctrl+x ctrl+a`)로 접습니다.

## 무엇을 읽나

- 세션·주간 한도, 컨텍스트, 비용은 Claude Code가 플러그인에 넘겨주는 값을 그대로 씁니다.
- 모델별 한도는 Claude Code가 넘겨주지 않아서, Anthropic의 사용량 조회 경로(`api.anthropic.com/api/oauth/usage`)를 직접 읽습니다. 세션의 구독 로그인은 Claude Code가 요청에 대신 붙이며, 플러그인 코드는 토큰을 볼 수 없습니다. 조회는 세션 시작 때와 턴이 끝날 때, 2분에 한 번 이하로 합니다.
- 다른 곳으로 보내는 데이터는 없습니다.

## 참고

- 구독 로그인이 아닌 경우(API 키 과금 등)에는 한도 칸 대신 컨텍스트 사용률만 표시됩니다.
- Claude Code의 플러그인 훅 API는 얼리 액세스라, Claude Code 버전에 따라 동작이 달라질 수 있습니다. 2.1.325에서 확인했습니다.
- 사용량 조회 경로는 공개 문서가 없는 내부 경로라, 응답 형식이 바뀌면 모델별 한도 칸이 사라질 수 있습니다.

# Claude Chat용 브라우저 확장

`chrome/` 폴더는 같은 배너를 **claude.ai 웹 화면**에 띄우는 Chrome 확장입니다. 위의 Claude Code 플러그인과는 별개로 동작합니다.

```
세션 ▰▰▰▰▰▰▱▱▱▱ 62% 18:40 │ 주간 ▰▰▰▰▰▰▰▰▱▱ 82% 월 12:00 │ Fable ▰▰▰▰▰▰▰▰▰▱ 86% 월 12:00  ×
```

화면 오른쪽 아래에 작은 막대로 뜨고, 누르면 초기화 시각 대신 남은 시간이 나옵니다. `×`로 그 탭에서만 숨길 수 있습니다.

## 설치

Chrome 웹스토어에 올린 것이 아니라서 폴더째로 불러옵니다.

1. Chrome 주소창에 `chrome://extensions` 를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 이 저장소의 `chrome` 폴더를 고릅니다.
4. claude.ai 탭을 새로고침합니다.

처음에는 배너에 "사용량을 아직 못 읽었어요"가 뜹니다. **claude.ai에서 설정 → 사용량을 한 번 열면** 그때부터 채워집니다(아래 "무엇을 읽나" 참고).

## 켜고 끄기

- 툴바의 확장 아이콘을 누르면 **배너 표시** 체크와 **위치**(오른쪽 아래 / 아래 가운데 / 오른쪽 위)를 바꿀 수 있습니다.
- 완전히 끄려면 `chrome://extensions` 에서 확장 자체를 끕니다.

## 무엇을 읽나

이 확장은 사용량 API 주소를 코드에 적어두지 않습니다. 대신 **claude.ai가 스스로 가져오는 응답을 지켜보다가**, 한도 정보가 들어 있는 응답을 발견하면 그 주소를 기억해 두고 이후 2분에 한 번 이하로 직접 다시 읽습니다.

- 그래서 설정 → 사용량 페이지를 한 번 열어줘야 첫 데이터가 잡힙니다.
- 로그인 정보는 브라우저가 claude.ai에 보내던 그대로 쓰이고, 확장이 토큰을 따로 읽거나 저장하지 않습니다.
- 읽은 값은 그 브라우저 안(`chrome.storage.local`)에만 남고, 밖으로 보내는 데이터는 없습니다.
- 권한은 `storage` 와 `https://claude.ai/*` 뿐입니다.

## 참고

- 응답 형식을 넓게 받아들이도록 만들어서, 한도 항목 이름이 바뀌어도 대체로 계속 동작합니다. 다만 사용량 API 자체가 공개 문서가 없는 내부 경로라 형식이 크게 바뀌면 배너가 비어 보일 수 있습니다.
- 모델별 한도가 여러 개면 사용률이 높은 2개까지만 보여 줄이 길어지지 않게 합니다.
- Claude 데스크톱 앱의 채팅 화면에는 적용되지 않습니다. 브라우저 확장이라 claude.ai 웹에서만 동작합니다.
